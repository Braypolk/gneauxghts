## Findings

1. **Terminal review cleanup can hide a required save failure.** `proposalOrchestration.closeReview` ends root metadata and dispatches `completionSucceeded` before awaiting `finishReviewDocument`. If saving remaining edits fails, its caller dispatches `completionFailed` while the workflow is already idle; the reducer rejects that event, leaving no visible error. The dirty model survives but the failure is invisible. The completed durable proposal must not be replayed. Owner confirmed and is using the existing idle error channel, with an actual failed-save composition assertion.
2. **Reload Disk is not bound to the retained review document.** The orchestration passes the review path, but `notepadProposalAdapter` aliases the callback to `refreshCurrentNote`; Notepad ignores the argument and refreshes the active document. Ordinary refresh also preserves dirty work as a conflict rather than applying an explicitly confirmed discard. For retained review A while B is visible, the new terminal `finishReviewDocument(A)` may save A's still-proposed body after A was explicitly dismissed. The approved no-pane contract requires disk adoption into the retained review document, leaving unrelated panes unchanged and preserving review/error state on read/adoption failure. Sent to owner/coordinator for real composition verification and correction.
3. **Presentation deletion contract remains partial in the initial frozen source.** `frontend-alternative.md` explicitly replaces proposal ensure/open/activate/reopen callbacks with one named workspace review-presentation operation. Initial reviewed `ProposalOrchestrationDeps` and `notepadProposalAdapter` still exposed/orchestrated those callbacks. Root body/hunk/snapshot ownership was migrated, but the accepted presentation-interface deletion is a separate incomplete requirement. Coordinator notified; owner correction in progress.

## Follow-up verification and disposition

1. Terminal cleanup catches a remaining-edit save failure and sends the existing idle `errorSet` event with the document title and save error. It does not re-enter the already-completed durable proposal workflow.
