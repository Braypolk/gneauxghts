# Reliable composable chat

## Objective

Run the real native chat against a live local model with synthetic notes, then complete structured recovery, safe evidence-budget delivery, and research reliability. The agent chooses capabilities and explicit dates. Preserve scoped historical/current evidence, exclusions, canonical validation, and app-owned runtime authority.

## Sequence

1. Establish a native end-to-end baseline and review answer semantics, activity, sources and citation navigation. Repair demonstrated harness/app failures.
2. Replace error-message recognition with structured tool outcomes carrying stable codes, retryability and recovery actions.
3. Make evidence delivery budget-safe: retain useful partial results, prevent lost/charged-but-undelivered read data and stalled continuations, and measure payload sizes.
4. Make research selection recoverable while delivering only actually read, validated evidence. Verify parent fallback and shared budgets.
5. Repeat representative live scenarios and run affected contracts, runtime, architecture and frontend checks. Record actual results and limitations.
6. Improve the worker's focused gathering/selection contract and counter-only observability; require actual worker read/selection/delivery in native current, history and discovery cases, with a separate excluded-scope direct-fallback case.

## Acceptance

A temporal follow-up request reads retained changes and canonical current status; excludes unchanged backlog and private data; distinguishes recorded facts and inferences; delivers resolvable citations. Recoverable failures supply an actionable contract. Budget exhaustion returns explicit partial coverage and preserves usable evidence. Research never returns unread selections as sources. Arbitrary date ranges, cross-note questions and follow-up turns compose the same capabilities.
