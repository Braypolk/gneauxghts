## Current authority and interpretation contracts

- [Shared assistant instructions](../../../src-tauri/src/chat/assistant_instructions.txt:7) already require read supporting passages beside each claim, exact quotes, attribution of related-note facts, unknowns/conflicts, and exclusion of discovery previews, earlier answers and pending edits as authority. [Lines 9–11](../../../src-tauri/src/chat/assistant_instructions.txt:9) distinguish current status, retained changes, text-change dates, real-world work, and pending publication. Therefore an offline baseline should measure failures against current contracts before adding more prompt text.
- [Current read tool](../../../src-tauri/src/agent_tools/interface.rs:56) says `coverage.complete` applies to its scope; only `wholeNoteComplete` establishes a complete current note. [Read payload coverage](../../../src-tauri/src/services/evidence/reads.rs:484) differentiates canonical note versus selected passages. Absence claims require complete relevant scope, not merely a successful selected read.
- [Citation preparation](../../../src-tauri/src/chat/citations.rs:57) matches exact delivered excerpt bytes and registers references; [rendering](../../../src-tauri/src/chat/citations.rs:81) accepts only references from this run and delivered sources. This proves link/source authority, not semantic support. Current title/property navigation is legitimate for claims about those exact fields; it cannot establish body insertion or task completion merely because it resolves.
- [Activity support](../../../src-tauri/src/services/evidence/reads.rs:405) refuses to promote broad canonical context into interval changes. The payload explicitly says recorded passage changes do not establish actor/work completion, and current context does not establish interval activity ([lines 425–458](../../../src-tauri/src/services/evidence/reads.rs:425)). `supported` timing must not become unsupported semantic certainty.
- [ADR 0009](../../../docs/adr/0009-allow-scoped-retained-activity-evidence.md:9) requires current evidence for present follow-ups and qualifies historical coverage. Historical additions/removals open retained revisions; title/lifecycle events are outside this authored-change interface. Baselines, discarded intermediates, cleared history, forgotten/excluded notes do not establish known work.
- [Prose guidance](../../../src-tauri/src/services/evidence/guidance.rs:6) separates event dates from text edits, preserves corrections/conflicts, and distinguishes planned work from completion; the latest edit alone does not select truth. [Checkbox guidance](../../../src-tauri/src/services/evidence/guidance.rs:7) distinguishes marker-bearing changes, reopened/removed/restored tasks, and unknown completion timing. [Deadline guidance](../../../src-tauri/src/services/evidence/guidance.rs:8) defines first-valid duplicates, independent children, Gregorian dates with no UTC conversion, and incomplete inventory behavior. These structured facts supplement exact excerpts; they must be included in fixture expectations where available.

## Small balanced evaluation rubric

Use atomic claim annotations with exact answer spans and exact cited source selectors. Score independently:

1. **Delivered authority:** reference exists in the answer's delivered sources; excerpt bytes/location match; discovery or unavailable sources never become authoritative.
2. **Claim support:** cited passages plus supplied facts establish every asserted actor, action, polarity, state and date. The implemented [rubric](README.md) uses `supported`, `unsupported`, `contradicted`, `unassessable`, and pending `unreviewed`; do not force unknown into false. Additional sources elsewhere in the answer do not rescue the claim's selected citation automatically.
3. **Temporal/source role:** distinguish authored-change timing from event/completion timing, historical state from current state, and title/properties/body. Compare history and current status without silently substituting one for the other.
4. **Inventory and summary consistency:** checkbox parsing/status, first-valid due annotation, children, fences, and completed/non-actionable classifications agree throughout the answer. A correct paragraph does not cancel a wrong table or summary.
5. **Scope and qualification:** complete relevant scope for absence/exhaustiveness; missing/partial evidence disclosed; suggestions are not recorded commitments; note records are not proof of real-world execution.

Recommended starting set: pair each negative with a minimally changed positive control: title versus historical body; preview versus admitted read; actual current status versus old retained checkbox; edit timestamp versus explicit event date; fenced versus real inline-code checkbox; open versus checked task; removed versus explicitly canceled/completed plan. Add a partial-coverage unknown and explicit-correction conflict case. Report category/claim counts and retained record selections, not a percentage described as production reliability. Automated structural checks can validate selectors, excerpts and hand-authored fixture labels; they cannot independently judge arbitrary natural-language entailment. Keep semantic annotations reviewable and measure any later model improvement on unchanged cases, with separate held-out examples.
