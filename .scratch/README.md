# Local project records

This directory is the repository's Markdown issue tracker and development
record, following [issue-tracker conventions](../docs/agents/issue-tracker.md).
Keep specs, decisions, issues and concise validation reports in Git. Generated
live-chat reports and screenshots remain local.

For the current chat work, start with the [chat index](chat-reliability/README.md).
It identifies completed milestones, the latest validation and the two remaining
follow-ups. Related folders retain the earlier decisions and measurements.
