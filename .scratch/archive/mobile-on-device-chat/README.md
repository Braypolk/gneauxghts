# Stopped on-device mobile chat investigation

2026-10-11: The user chose remote mobile chat with the same providers as desktop. This experiment is historical, not an implementation queue. Follow [mobile remote chat implementation](../mobile-remote-chat.md). On-device semantics remain active and independent.

The isolated UIKit simulator app tested the already-pinned LiteRT-LM 0.18.0 framework with synthetic Qwen3-0.6B messages and tools. It made no production chat-provider changes and did not access the vault. CPU and Metal generation ran; the newer INT4 artifact produced parsed tool calls and structured formatter arguments. Tool-result serialization depended on the artifact's embedded template. Native parser errors could emit multiple terminal callbacks, requiring callback userdata to outlive the first terminal signal. The experiment latched the first outcome and retained userdata through process lifetime.

These are bounded feasibility observations, not full application or physical-device acceptance. The model's 4,096-token context also could not accommodate the app's existing desktop context reserves; the core prompt and tools alone measured 3,248 tokens before history and note evidence. The final CPU run completed after the callback-lifetime correction; a final CPU/Metal/coexistence matrix and production integration were cancelled by the scope change. No phone RAM allowance or reliable desktop chat parity was established.

[Source research and artifact pins](chat-runtime-research.md) retain the model/template, sampler and callback cleanup findings. On 2026-10-12, the cancelled experiment's probe source, build/summarizing scripts, stale interface snapshot, downloaded chat weights and temporary build/cache/report artifacts were removed. The native `success` field recorded execution completion, not all-case acceptance; the summarizer's truncation assertion was unfinished when the investigation stopped. This record is historical evidence, not a passing product test suite or a runnable reproduction guide.
