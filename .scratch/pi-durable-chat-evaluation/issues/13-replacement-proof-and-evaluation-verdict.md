Status: ready-for-agent

Follow [the spec](../spec.md). The prior experiment deleted zero production
functions. Feature passes alone cannot establish reduced maintained coordination.

## Work

- Re-run final compiler/architecture exclusion checks including research,
  attachments, projection and startup; forbid hidden native/proxy fallback.
- Perform a bounded removal experiment for superseded modules/functions in an
  isolated comparison checkout/build. Preserve exact diff and reproduction
  evidence; the deliverable branch keeps its ordinary default runtime intact.
- Re-run required native gates on the removal build. Record actual removals,
  exclusions and retained policy separately from omissions. Compare state machines,
  stores, recovery paths, caller obligations and added adapters/dependencies;
  physical line counts are secondary.
- Compare issue 01 baselines with equivalent short/long fixtures and live journeys:
  IPC, latency, cancellation, memory, listeners, pagination, retained document
  families, collection/retention and storage growth.

## Acceptance

- Final gates cannot construct/use legacy conversation/run/review coordination or
  Rust model/tool loop, including child research. Empty tables support but cannot
  replace this proof; each concern has one authoritative owner.
- The ledger names code removed/excluded and retained evidence/editor/NoteTimeline/
  effect services. Added recovery/policy cost is disclosed, not called automatic
  Pi savings.
- Results separate bridge cost from provider latency and disclose material
  regressions/scale limits/unresolved gates without unsupported performance wins.
- Deliver run instructions, hands-on checklist, matrix and continue/narrow/
  adoption-work/defer/reject verdict. Identify real user feedback separately.
- Reconcile ticket progress and archive outcome. Do not merge/default-enable,
  migrate original data or revise ADR 0001 into production adoption here.
