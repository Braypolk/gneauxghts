## Review decisions and limits

No source rewrite was justified by file length alone. Async ownership/correlation defects, copied test policies, unsupported whole-interface casts and forwarding-only modules were concrete causes of risk and were addressed directly. Tiny pure helpers with meaningful boundary policy remain. Existing domain behavior tests are retained; class/style assertions were replaced only where observable state provides a stronger oracle. The browser fixture is isolated and deterministic, emits real event shapes through the app bridge, and never invokes a provider or external model.
